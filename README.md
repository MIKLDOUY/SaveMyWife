# SaveMyWife — Veille Essais Cliniques TNBC

Outil ultra-léger pour surveiller les essais cliniques pertinents pour Céline Douy‑Zorgnotti (TNBC métastatique).

## Fichiers
- `medical_report.md` : dossier médical structuré
- `watcher.py` : script unique de veille
- `results.txt` : résultats générés automatiquement

## Exécution
Ce projet est conçu pour être utilisé depuis un téléphone via GitHub.
Le script `watcher.py` peut être exécuté :
- via GitHub Codespaces
- via un ordinateur
- via un serveur léger

## Objectif
Aider l’oncologue à gagner du temps en fournissant :
- une veille automatique
- un filtrage simple
- un dossier médical structuré
- aucun avis médical
